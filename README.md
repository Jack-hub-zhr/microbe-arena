# 微生物进化大赛 · Petri Arena（Liquid Glass 重构版）

一个培养皿、一群原始单细胞、一只看不见的手。
玩家扮演「上帝之手」投喂、点化、天罚、瘟疫，观察光合者、分解者、猎手如何在几十万个世代里
从争抢营养一路演化到分工协作的多细胞生命。

> 本版本在原版基础上重写了演化引擎、3D 场景与全部界面层，
> 并**引入了完整的 Liquid Glass（液态玻璃）设计语言**。

---

## 一、快速开始

```bash
npm install
npm run dev        # 本地开发（默认 http://localhost:5173）
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 预览生产构建
```

技术栈：Vite 5 + React 18 + TypeScript 5 + Tailwind CSS 3 + Three.js 0.169。
构建产物是纯静态文件，`dist/` 可直接丢到任何静态托管上。

### 画质参数（URL 查询串）

| 参数 | 作用 |
| --- | --- |
| `?q=high` | 锁定高画质（关闭自动降级） |
| `?q=low` | 锁定低画质（关闭阴影、降低分辨率） |
| 默认 | 按实时帧率自动升降档 |

## 三、设计方向：为什么长这样

界面最容易落入的坑是「什么都不指定」——那会得到训练数据的中位数，和所有人做的都一样。
所以这里的每个轴都是**刻意选过**的，并且说得出理由：

| 轴 | 选择 | 理由 |
| --- | --- | --- |
| 强调色 | 黄铜 `#d9a441` | 仪器刻度盘的颜色。避开靛蓝/紫罗兰带（那是 Tailwind 的默认色，一眼就是「没人选过」）。全局只用这一种强调色 |
| 中性色 | 暖石墨 ramp（`#100f0d` → `#2a2620`） | 纸与工作台的暖调。库存 slate/zinc 的冷灰是另一条 tell |
| 字体 | IBM Plex Serif（标题）/ Sans（界面）/ Mono（数据） | 同一工程感超级家族，三个声部。不是 Inter / Geist / Roboto 那一批自动默认值。中文落到宋体/黑体栈 |
| 圆角 | 4 / 8 / 14 / 20 四档，按角色分配 | 不是「所有东西都最圆」。胶囊只留给用户明确点名要的控件 |
| 深度 | 表面层级 + 发丝线 + 一道顶部高光 | **零霓虹外发光**。深色界面靠对比和间距，不靠 glow |
| 动效 | 只保留表达状态的（面板从触发按钮生长、数值闪烁、事件进场） | 装饰性循环动画（星云漂移、扫光、呼吸光晕）全部删除 |
| 图标 | 29 个手绘线性 SVG（21 性状 + 5 职能 + 3 路线 + 3 事件） | 不拿 Unicode 字形（☀ ⛭ ◉ ✦）冒充图标 |
| 版式 | 左文案 / 右实物的不对称布局 | 介绍页不再是「居中大标题 + 四张等宽图标卡 + CTA」 |
| 文案 | 句式、具体数字、不用营销词 | 「六十多项」这类空话一律不写 |

> 这轮改动参照了开源社区的 **unslop** 系列（[heydamir/unslop](https://github.com/heydamir/unslop)、
> [iamneilroberts/claude-skills 的 unslop-ui](https://github.com/iamneilroberts/claude-skills)，
> 均为 CC BY 4.0 / MIT）的判定清单：
> 默认 shadcn 观感、AI 紫、满屏渐变、动效过多、全员胶囊、暗色霓虹、emoji 当图标、
> Inter 这类默认无衬线、居中 hero + 三卡 + CTA 骨架。
> 其中的确定性扫描器 `devibe_scan.py` 可以在 CI 里当门禁。

| 多细胞起源 | 群体感应 | 费氏弧菌的「分子投票」 | 5 亿年前 | 群体共享能量 ×1.8 |
| 多细胞起源 | 凋亡程序 | 多细胞生物的受控细胞死亡 | 10 亿年前 | 成员牺牲自己供养群体 |

**演化是有方向的，但不是被写死的**：

- 新性状必须**先满足前置**（如「触手」需要先有「刺丝泡」），
  因此沙盒里的演化路径天然就是真实历史上的顺序。
- 获得新性状时，**能解锁后续演化、能打开多细胞路线的性状权重更高** ——
  这正是真实世界里「打开新方向」的性状所受到的偏好。
- 丢失性状时**不会拆断依赖链**：丢了线粒体，溶酶体也一起消失。
  复杂性状一旦建立就能稳定保持。

### 4.2 三条真实的多细胞化路线

多细胞化在地球上发生过不止一次，三条路线各有不同的必要条件与结局：

| 路线 | 现实原型 | 必要条件 | 结局 |
| --- | --- | --- | --- |
| **粘菌路线** | 黄色黏球菌 *Myxococcus xanthus* | 黏连蛋白 + 群体感应 | 资源耗尽时长出**子实体**，播撒休眠孢子重新播种培养皿 |
| **团藻路线** | 团藻 *Volvox* | 黏连蛋白 + 眼点 | 群体变成**整体漂游的球体**，体内出现体细胞 / 生殖细胞分工 |
| **动物路线** | 领鞭毛虫 → 海绵 | 黏连蛋白 + 触手 | 出现**神经样信号与集体迁移**，能整体躲开捕食者 |

三条路线在 3D 里有完全不同的身体形态：粘菌长出发光的孢子囊，
团藻是一个半透明的绿色球体，动物路线是会变形的粉色集体身体。

### 4.3 三件真实发生在地球上的大事

这些事件**按演化进度自然触发**，不是按时间轴硬播的：

| 事件 | 年代 | 触发条件 | 真实后果 |
| --- | --- | --- | --- |
| **大氧化事件** | 24 亿年前 | 产氧光合的个体占比 ≥ 12% | 62% 的厌氧生物被自己的产物毒死；此后氧气成为燃料，「有氧呼吸器」成为压倒性优势 |
| **雪球地球** | 7 亿年前 | 大氧化之后，种群足够大 | 全球冰封，代谢放缓、食物锐减，**只有能形成芽孢的谱系活下来**（其余约 42% 冻毙） |
| **寒武纪爆发** | 5.41 亿年前 | 第一条多细胞化路线达成 | 突变率临时 ×2.5，身体蓝图集中涌现 |

## 八、引擎改动详解

### 9.1 食物不会溢出培养皿

```ts
clampToDish(x, y, margin = 12) {
  const limit = this.innerRadius - margin;
  const d = Math.hypot(x, y);
  if (d <= limit) return { x, y };
  const k = limit / (d || 1);
  return { x: x * k, y: y * k };
}
```

`spawnFood()` 是唯一入口，所有食物都从这里出去，因此不可能绕过夹紧。
贴着皿壁投喂时，食物会沿壁堆叠而不是掉到皿外。

> 实测：连续三次贴着皿沿投喂后，食物最远距离 866.0 < 皿内半径 884.0，溢出数 0；
> 5000 tick 演化全程的溢出检查同样为 0。

### 9.2 食同族（cannibalism）

```ts
preyScore(predator, prey) {
  const atk = this.attackOf(predator);
  const def = this.defenseOf(prey);
  // 常规捕食：攻击力明显压制 + 体型不占劣势
  if (atk > def * 1.45 && predator.genome.size >= prey.genome.size * 0.94) return 1;
  // 食同族：同为猎手，体型更大即可吞食同类
  if (predator.strategy === 'hunter' && prey.strategy === 'hunter'
      && atk > def * 1.04
      && predator.genome.size > prey.genome.size * 1.1) return 0.85;
  return 0;
}
```

猎手在找不到常规猎物时会主动逼近同类（饥饿度越高追得越凶），于是「食同族」成为真实存在的生态行为，
而不是一个摆设开关。事件流里有独立条目：`食同族：猎手 #777 吞噬了同族 #1054`。

### 9.3 多细胞体的功能分化

多细胞体不再只是「黏在一起的几个点」：

1. **聚合**：带黏连蛋白、色相差 < 25° 的细胞距离 < 24 时成团，之后继续吸收游离细胞，上限 14。
2. **积累世代**：每 60 tick 群体 `rounds` +1（一次「群体世代」）。
3. **功能分化**：`rounds ≥ 1` 且成员 ≥ 4 时触发 `assignRoles()`，按基因特质打分派工：

   | 职能 | 基因偏好 | 实际作用 |
   | --- | --- | --- |
   | 核心细胞 | 叶绿体 + 高效率 | 产能最高、行动最慢，把共享池分发给同伴 |
   | 采集工 | 鞭毛 + 高速度 | 游速 ×1.4、进食 ×1.55，把收成存入共享池 |
   | 守卫细胞 | 毒素 + 外壳 | 防御 ×2.0、攻击 ×1.6，死守群体边界 |
   | 繁殖体 | 高效率 + 线粒体 | 繁殖阈值 ×0.6，持续补充成员 |
   | 养护细胞 | 感应纤毛 | 从共享池抽取能量治疗受伤同伴 |

4. **共享能量池**：采集工存入 → 核心分发 / 养护治疗 → 群体整体存活率显著高于独居个体。
5. **可视化**：不同职能的细胞在 3D 场景里有不同的颜色、尺寸与表面特征（守卫带刺、繁殖体拉长、核心更饱满），
   群体之间绘制连接丝与柔和光晕 —— 一眼能看出「这已经是���个整体」。
6. **退化保护**：成员少于 3 时职能自动解除，群体解散，个体回归自由生活。

> 实测：多细胞体稳定形成并完成分化，职能分布为核心细胞 / 采集工 / 守卫细胞 / 繁殖体 / 养护细胞 同时存在。

### 9.4 分解者与养分循环

新增 `溶酶体（lysosome）` 细胞器：

- 有溶酶体且攻击性不高 → 生态位判定为**分解者**。
- 分解者吃尸体碎屑的收益 ×2.5，并把一部分物质还原成全局 `nutrient`（培养基养分）。
- 养分越高，培养基自动补充的有机养分越多（`foodPerTick × (0.5 + 0.5 × nutrient)`），生态循环闭合。

> 引擎默认参数：`foodPerTick = 4.2`、`mutationRate = 0.75`，
> 是用 5 组随机种子跑 5000 tick 扫出来的平衡点（种群稳定在 300~380 之间）。
- 其他生物吃碎屑只有 ×0.45 收益，碎屑主要归分解者。

### 9.5 性能

- 邻域查询从 O(n·m) 换成均匀网格空间索引（`SpatialGrid` / `FoodGrid`），
  200~550 个体 × 数百份食物的每帧开销降到近似 O(n)。
- 进食阶段改为「打标记 → 统一清理」，避免在遍历中 splice 破坏索引。
- 繁殖阈值、代谢、攻防等数值全部按职能系数派生，便于继续调平衡。

### 6.6 生态平衡

开局由**三条创始谱系**接种 200 个单细胞（同谱系色相相近，因此可以聚合成多细胞体，
不同谱系颜色可辨，一眼能看出谁和谁是一家人）。

5000 tick × 5 组随机种子实测：

| 种子 | 种群 | 多细胞体（已分化） | 累计捕食 | 食同族 | 出现职能数 | 食出皿 |
| --- | --- | --- | --- | --- | --- | --- |
| A | 374 | 2 / 2 | 2575 | 214 | 4 | 0 |
| B | 375 | 2 / 2 | 1676 | 112 | 3 | 0 |
| C | 375 | 8 / 6 | 1083 | 18 | 4 | 0 |
| D | 295 | 7 / 3 | 986 | 32 | 4 | 0 |

五个生态位（光合者 / 采集者 / 共生体 / 分解者 / 猎手）全部出现，
多细胞体稳定形成并完成功能分化，食同族稳定发生，食物从不溢出培养皿。

## 九、界面改动详解

### 9.1 Liquid Glass 材质

`src/lib/liquid-glass.ts` 的工作方式：

1. 用 Canvas 逐像素计算**圆角矩形有符号距离场**，只在边缘带内产生位移，生成一张位移贴图
   （R 通道编码水平位移、G 通道编码垂直位移、128 表示不位移）。
2. 贴图转成 data URI 交给 SVG `feImage`，再用 `feDisplacementMap` 通过
   `backdrop-filter: url(#id)` 应用到**背后的真实 DOM 内容**上 —— 这是真折射，不是模糊。
3. 可选逐通道三次不同强度的位移 + `feBlend` 叠加，得到边缘的棱镜色散。
4. Safari / Firefox 不支持 `backdrop-filter: url()`，自动降级为高保真磨砂玻璃。
5. 运行时校验：若浏览器声明支持但实际渲染失效，自动回落到纯磨砂，面板永远不会变成空白。

CSS 层面（`index.css`）提供材质外观：半透明渐变、1px 玻璃描边、内侧高光、
底部反光、**棱镜色散边**（`mask-composite` 抠出的渐变描边）、以及走合成层的高光扫光。

### 9.2 从按钮生长出来的展开动画

```ts
// 展开原��� = 用户刚刚点击的那个按钮的中心
const originX = clamp(anchor.left + anchor.width / 2 - left, -60, width + 60);
const originY = clamp(anchor.top + anchor.height / 2 - top, -60, height + 60);
setStyle({ transformOrigin: `${originX}px ${originY}px` });
```

面板以 `transform: scale(.22) → scale(1)` + 透明度过渡展开，起点就是那个按钮。
右侧三颗按钮（实时圆饼 / 榜单 / 图鉴 / 编年史）共用同一个抽屉 —— 点哪一个，
抽屉就从哪一个按钮的位置长出来。

> 实测：抽屉 `transform-origin` 还原出来的坐标与被点击按钮中心误差 < 3px。

### 9.3 动画不会「卡在半路」

浏览器繁忙时 CSS 动画可能长时间停在 pending 状态，元素会被钉在关键帧起点
（`scale(.22)` / `opacity:0`）而永远长不出来。`usePopReveal()` 在动画启动 320ms 后检查一次，
若动画确实没有推进，就摘掉动画类让面板直接呈现展开态 —— **面板永远可见**。

### 9.4 实时圆饼图

`EcologyPie` 用 SVG `stroke-dasharray` + `stroke-dashoffset` 画圆环分段，
比例变化时由 CSS 过渡平滑补间（640ms），因此是真正「实时跳动」而不是每帧重绘。
收起状态下它就嵌在右侧那颗胶囊按钮里（58px），展开后是抽屉里的大圆环（148px）+ 占比条 + 数量。

## 十、性能与自适应画质

三维场景在弱设备（尤其是软件渲染）上是主要瓶颈。因此内置了自动降档：

| 档位 | 分辨率 | 阴影 | 群体光晕 | 冷凝水珠 |
| --- | --- | --- | --- | --- |
| 高 | dpr ≤ 1.25 | 开 | 开 | 开 |
| 中 | dpr ≤ 1 | 关 | 开 | 关 |
| 低 | dpr 0.6 | 关 | 关 | 关 |

每 12 帧（或 1.2 秒）评估一次平均帧时间：> 46ms 降一档，< 17ms 升一档。
另外演化循环本身有 8ms/帧的预算上限，慢机器上界面依然跟手。

> 注意：这套降档机制对「软件渲染」的环境非常有效（实测帧率提升约一倍），
> 在有独立 GPU 的普通设备上会稳定保持高画质。
